# حساباتي ERP

نظام إدارة الموظفين والحضور والسلف والرواتب والخزائن — يشتغل كموقع (PWA) وكتطبيق أندرويد (APK) عن طريق Capacitor.
التطبيق كله في ملف واحد `index.html` والبيانات بتتخزن محلياً على الجهاز، ومعاها مزامنة سحابية اختيارية عبر Firebase.

## محتويات الفولدر

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كله (واجهة + منطق + مزامنة سحابية + زر الرجوع) |
| `manifest.json` | إعدادات الـ PWA (الاسم والألوان والأيقونات) |
| `sw.js` | Service Worker للعمل بدون نت (للنسخة الويب فقط) |
| `icons/` | أيقونات الـ PWA |
| `package.json` | الحزم وأوامر البناء |
| `capacitor.config.json` | إعدادات تطبيق الأندرويد (الاسم، المعرّف `com.hesabati.erp`، الـ splash) |
| `scripts/build-www.mjs` | يبني فولدر `www/` وينسخ المكتبات محلياً (أوفلاين كامل) |
| `resources/` | صور مصدر الأيقونة والـ splash لتوليد موارد أندرويد |
| `firestore.rules` / `firebase.json` | قواعد أمان Firestore وإعداد الاستضافة |
| `.gitignore` | يتجاهل `node_modules` و`www` وملفات البناء والـ keystore |

> `www/` و`android/` بيتولّدوا بالأوامر تحت، مش لازم ترفعهم على Git (`android/` ممكن ترفعه لو عايز تحتفظ بتعديلاتك فيه).

## 1) تشغيل سريع كموقع

```bash
npm install
npm run serve        # يفتح على http://localhost:8080
```

لازم يتشغّل من رابط (مش بفتح الملف مباشرة) عشان الـ Service Worker يشتغل.
للنشر: ارفع محتوى `www/` على أي استضافة HTTPS (Firebase Hosting / Netlify / GitHub Pages).

## 2) بناء تطبيق الأندرويد (APK)

**المتطلبات:** Node.js 22 أو أحدث، و Android Studio (آخر إصدار) ومعاه JDK 21.

```bash
npm install
npm run android:add    # مرة واحدة: يبني www ويضيف مشروع android/
npm run assets         # مرة واحدة: يولّد الأيقونات والـ splash من فولدر resources/
npm run android        # يبني www ويزامن ويفتح Android Studio
```

من Android Studio: وصّل موبايلك (Developer options ← USB debugging) واضغط **Run ▶** للتجربة.

بعد أي تعديل في `index.html`:

```bash
npm run sync           # يعيد بناء www وينسخه لمشروع أندرويد
```

### إخراج APK / AAB للنشر

Android Studio ← **Build ← Generate Signed App Bundle / APK** ← اختار APK (للتثبيت المباشر) أو AAB (لـ Google Play) ← أنشئ keystore جديد.
**احتفظ بملف الـ keystore وكلمة سره في مكان آمن** — من غيره مش هتقدر تحدّث التطبيق بعدين.

## زر الرجوع

الرجوع في التطبيق بيرجعك للخطوة اللي قبلها بدل ما يقفل التطبيق، بالترتيب ده:

1. لو فيه نافذة أو قائمة أو الملف الشخصي مفتوح ← تتقفل (وإذا كنت جوه "تغيير الاسم/كلمة المرور" بيرجعك للقائمة الرئيسية للملف الشخصي).
2. لو انت في شاشة غير الرئيسية ← يرجع للشاشة اللي كنت فيها قبلها (بنفس ترتيب تنقلك).
3. لو انت في الشاشة الرئيسية أو شاشة تسجيل الدخول ← تظهر رسالة "اضغط رجوع مرة أخرى للخروج"، والضغطة التانية خلال ثانيتين بتقفل التطبيق.

جوه تطبيق الأندرويد ده بيشتغل بمكدّس داخلي عن طريق إضافة `@capacitor/app` (مش بيعتمد على سجل المتصفح لأنه غير مضمون جوه الـ WebView). في المتصفح والـ PWA بيستخدم `history` بنفس السلوك. الكود في `index.html` تحت عنوان "زر الرجوع".

## الفرق بين التطبيق والمتصفح

- **تصدير Excel والنسخ الاحتياطي:** جوه التطبيق بيتحفظ الملف وتفتح شاشة المشاركة (حفظ في الملفات / Drive / واتساب...)، لأن التنزيل المباشر مش بيشتغل في الـ WebView.
- **طباعة القسيمة:** الـ WebView مفيهوش طباعة، فالزر جوه التطبيق بيتحول لـ "مشاركة الإيصال" وبيشارك نص القسيمة. الطباعة العادية شغالة في المتصفح.
- **أوفلاين:** المكتبات (Chart.js و SheetJS و Firebase) بتتنسخ جوه التطبيق وقت البناء، فالتطبيق يشتغل بدون نت من أول مرة. الاستثناء الوحيد خط Cairo (بيتحمل من Google Fonts) وجوه الأوفلاين بيرجع لخط النظام.
- **تثبيت النسخة الجديدة:** التطبيق نفسه جوه الـ APK، فأي تعديل لازم تعمل `npm run sync` وتبني نسخة جديدة وتثبتها.

## 3) تفعيل المزامنة السحابية (اختياري، مرة واحدة)

1. console.firebase.google.com ← Add project
2. Authentication ← Sign-in method ← Email/Password ← Enable
3. Firestore Database ← Create database ← Production mode
4. Firestore ← Rules ← الصق محتوى `firestore.rules` ← Publish
5. Project settings ← Your apps ← Web (`</>`) ← انسخ القيم الستة والصقها جوه `FIREBASE_CONFIG` في `index.html` (دور على الاسم)

بدون الخطوة 5 التطبيق يشتغل محلي فقط. للنشر بالأمر: `firebase deploy` (بعد `npm run build`).

## ملاحظات

- مفيش "نسيت كلمة المرور" لأن الحسابات مش مربوطة بإيميل حقيقي، فاعمل نسخة احتياطية دورياً (الملف الشخصي ← تصدير نسخة احتياطية).
- بعد تغيير الأيقونة: امسح التطبيق من الموبايل وثبّته تاني.
- لو شريط الحالة أو شريط التنقل السفلي ظاهر فوق المحتوى على بعض الأجهزة، ده يتعدّل من القواعد الخاصة بـ `html.is-native` في قسم "تطبيق الأندرويد" داخل `index.html`.
- لتصحيح الأخطاء من الكمبيوتر: غيّر `webContentsDebuggingEnabled` إلى `true` في `capacitor.config.json` ثم افتح `chrome://inspect`، وارجعه `false` قبل النشر.
